# TryHackMe-Just-a-VPN-Login

TryHackMe Lab: Just a VPN Login – Lumma Stealer Investigation

Overview

Completed the Just a VPN Login room on TryHackMe, focusing on malware investigation and threat intelligence analysis involving Lumma Stealer, an information-stealing malware.

The investigation involved analysing file hashes, IP addresses, network infrastructure, and HTTPS certificates to understand the indicators associated with the malware.

What I Investigated

1. File Hash Analysis

* Investigated the provided file hash to identify information related to the suspicious file.
* Used hash-based threat intelligence to understand the malware’s reputation and possible associations.
* Learned how file hashes help analysts identify and track malicious files.

2. IP Address Investigation

* Analysed suspicious IP addresses associated with the investigation.
* Explored IP ownership and network information.
* Learned about ASN (Autonomous System Number) and how it helps identify the network or organisation responsible for an IP address.

3. HTTPS Certificate Investigation

* Investigated HTTPS certificates associated with suspicious infrastructure.
* Learned how certificate information can provide useful indicators during threat investigations.
* Explored how certificate details can help identify relationships between suspicious domains and infrastructure.

4. Malware Research – Lumma Stealer

* Learned about Lumma Stealer, an information-stealing malware.
* Explored its role in collecting sensitive information from compromised systems.
* Read the research report “Behind the Curtain: How Lumma Affiliates Operate” to understand how Lumma affiliates operate and distribute the malware.

Key Learning Outcomes

* Understanding malware investigation through file hashes and IP addresses.
* Learning how to use ASN information during infrastructure analysis.
* Understanding the importance of HTTPS certificate investigation.
* Developing threat intelligence and IOC analysis skills.
* Learning how threat research reports help analysts understand malware operations and attacker infrastructure.

Conclusion

This lab helped me understand how different indicators, such as file hashes, IP addresses, ASN information, and HTTPS certificates, can be combined to investigate suspicious infrastructure and malware activity.

It was a valuable hands-on learning experience in malware investigation and threat intelligence analysis.
